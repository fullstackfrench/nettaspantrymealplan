Add a meal to the weekly menu

A step-by-step guide for making a meal available in both one-time boxes and weekly subscriptions.

1. Set up the meal

  1. Open Admin → Meals and click Edit beside the meal.
  2. Under Purchase availability, check both Available for one-time purchase and Available for subscription.
  3. Under Sizes & prices, configure each size you want to offer:
    • Check Active.
    • Enter a positive whole-number serving count, such as 1, 2, or 4.
    • Enter a price greater than $0, with no more than two decimal places.
    • Check One-time purchase for each size customers can buy in a one-time box.
    • Select Standard subscription size for exactly one size—the portion subscribers will receive.
    You may offer several one-time sizes. Subscriptions use the single designated standard size, which can also be sold in one-time boxes.
  4. Check Show on the customer menu, then click Save changes. Click OK in the confirmation popup. The meal should be marked Visible.

2. Include the meal and publish the week

  1. Open Admin → Weekly Menus and select the week you want customers to order from.
  2. Find the meal and click Add. Its button should say On the menu. If it already says that, leave it selected.
  3. Check the week’s status. If it says Draft, click Publish this week. If it already says Published, leave it published.
  4. Open or refresh This Week’s Menu. Select One-time box and confirm the meal appears, then switch to Weekly subscription and check again.
If a meal is missing: Check all three requirements: it is Visible, it is On the menu in the latest published week, and its size is available for the selected order type. A meal missing only from subscriptions usually needs Available for subscription enabled or a valid Standard subscription size selected. Publishing a week does not automatically enable either purchase type.
The customer menu displays the latest published week by its week-start date. Save meal edits before checking the customer menu.
